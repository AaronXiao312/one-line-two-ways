# One Line, Two Ways

A small browser game about checking metro train destinations and branch paths before boarding. Station names and routes are fictionalized; this is not a real Shanghai Metro guide.

## Play locally

Open `index.html` in a desktop browser. No build step or external game library is required.

## Publish with GitHub Pages

Keep the project files at the repository root. In repository Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, then save. The live game will be at `https://aaronxiao312.github.io/one-line-two-ways/`.

## Pages

- `index.html` — overview
- `game.html` — playable three-trip prototype
- `domain.html` — domain and system design
- `process.html` — development timeline
- `assets/` — styles, game logic, and system graph
