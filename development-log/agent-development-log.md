# Development log

## 2026-10-19 — Concept and first playable web version

- **Student decision:** Use a real Shanghai Metro route mix-up on the way to a west-side Burger Festival as the game's domain. Keep the learning goal focused on checking destination and branch information rather than trusting a line number by itself.
- **AI contribution:** Organized the supplied experience into a design brief and system graph, then implemented the first browser prototype and project website using plain HTML, CSS, JavaScript and SVG.
- **Design decision:** Use fictional station names and a simplified branch map. The prototype is for learning the route-reading decision and must not be used for real travel.
- **Current prototype:** Three progressive trips cover reading a terminal, noticing a branch split, and choosing under delay pressure. Players can wait, board, check the next stop, recover by transferring, and retry.
- **Playtest status:** No external playtest has been recorded yet. Add observations and revisions after a classmate plays the game.
- **Publishing status:** Prepared for a GitHub repository and GitHub Pages. A public repository and live site have not been created yet.
